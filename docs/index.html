How accurately do data agents answer real wealth-management questions?

Cortex-Bench scores agents on 190 questions against a 22-table, 58-million-row synthetic Indian wealth-management warehouse. Nine tiers, from schema linking to multi-turn sessions, including a tier whose correct answer is that the question cannot be answered from the data. Every row below was executed by the organizers, and every score is a mean over repeated runs.

Null floor (answer nothing) is a control, not a competitor: it returns the empty set for every task, reads no data and calls no model. It scores 4.7% because some questions in this benchmark genuinely have no rows to return. Read every other score against it.

Why the spread is printed. Two identical runs of the same agent — same model, same questions, temperature 0 — disagreed on 21% of tasks. A single-run number implies a precision that does not exist, so three runs are required and every run's score is published in the entry file. pass@N counts tasks solved at least once; pass^N counts tasks solved every time. The gap between them is churn.

Neo-Cortex carries a Legacy pill because it was measured against an earlier data snapshot. Gold answers are bound to the snapshot they were compiled from, so that figure is real but not comparable with the ranked rows, and it takes no rank. Its captured SQL cannot be re-executed either — the agent emitted parameterised SQL whose bound values were never recorded — so a comparable number needs the agent re-run, not the capture re-scored.

A dash is not a zero. Hover it to see why the metric was not measured.

03

Cost and latency against accuracy

What each system spends to get where it got. Accuracy runs along the horizontal axis, so bottom-right is best: accurate and cheap, accurate and fast. Correctness alone is not the whole picture on a 58-million-row database — a query that returns the right answer in six minutes is not a usable one.

Latency and cost come from the live agent runs. Neither is currently folded into the score: an efficiency metric in the spirit of BIRD's VES is on the roadmap, and until it exists a slow correct answer ranks exactly like a fast one.

04

Method, in brief

190 execution-scored questions, 9 tiers, one frozen snapshot.
Gold answers compiled by executing reference SQL against that snapshot.
Synthetic data: deterministic, seed 42, FK-integrity validated, no PII.
Scored by eval/score_cortex_bench.py, unmodified, by the organizers.
Every run's score published, including the bad ones.

Each row on this board is a JSON file in results/, validated in CI against schema/leaderboard_entry.schema.json. This page is regenerated from those files and holds no data of its own — edit the JSON, never the HTML. The provenance of any number is git log results/<entry-id>.json.

To submit, open a pull request adding one entry file. Known defects are logged in ERRATA.md, and what the data does and does not model is in DATASHEET.md.
